Auto-Remake настройки по аккаунтам

Как работает: при синхронизации аккаунта (раз в час), для каждого reel с views ↑ ×N за M часов автоматически:

  1. скачивается в R2 (если auto_download_media)
  2. анализируется Whisper + Vision + scenes + hook (если auto_analyze_media)
  3. извлекается ContentRecipe
  4. создаётся remake через Runway gen4.5 с подставленными RemakeParams
  5. uniqify (если auto_uniqify)
  6. публикуется в auto_posting_target (если auto_publish)
